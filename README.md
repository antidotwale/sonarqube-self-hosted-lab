# sonarqube-self-hosted-lab

Self hosted SonarQube in Docker, scanning a sample app from CI and from the CLI scanner.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client. Any secrets, keys or tokens shown in test data are fake.

## What this builds

SonarQube running in Docker with a database, a quality gate, a sample app scanned from a pipeline, and the CLI scanner used on code that sits outside CI.
